# Loan Data Management (PWA)

Installable web app by Clouds Dev Solutions — cloudsdevsolutions@gmail.com

## Deploy on GitHub Pages
1. Upload all files in this folder to a GitHub repo (keep the `icons` folder).
2. Repo → Settings → Pages → Source: `main` branch, `/ (root)` → Save.
3. Open `https://<username>.github.io/<repo>/` and install:
   - Android/Chrome/Edge: "Install app" button or browser menu → Install.
   - iPhone/iPad (Safari): Share → Add to Home Screen.
